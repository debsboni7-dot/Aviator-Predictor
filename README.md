# Aviator Predictor / Aviator Lens

Prototype web mobile-first d'analyse descriptive des multiplicateurs Aviator.

## Fonctions actuelles
- Tableau de bord responsive, adapté aux téléphones.
- Import de multiplicateurs par collage ou fichier CSV/TXT.
- Statistiques descriptives : moyenne, médiane, fréquences par tranche et 20 derniers résultats.
- Conservation locale de l'historique dans le navigateur.
- Jeu de données de démonstration clairement identifié.

## Limites importantes
Ce prototype ne prédit pas le prochain résultat et ne garantit aucun gain. Les résultats passés ne permettent pas de déduire le prochain multiplicateur. Il ne se connecte pas à un compte 1xBet et ne contourne aucune protection. Aucun flux automatique officiel/public n'est configuré à ce stade.

## Déploiement GitHub Pages
Dans le dépôt : **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Après publication, GitHub affichera l'adresse du site.

## Tester
Ouvrir `index.html` dans un navigateur ou publier le dépôt avec GitHub Pages.
